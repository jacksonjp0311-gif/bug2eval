# 10-second demo recipe

The best Bug2Eval demo is visual and concrete.

1. Show one failing test in a tiny repository.
2. Show the one-line fix being committed.
3. Run `bug2eval capture ...`.
4. Show `Validation: VALID`.
5. Run the resulting `.b2e` against a second agent/model.
6. End on: `PASS` and the line **"The bug became a benchmark."**

Keep the clip under 20 seconds. Do not explain the architecture before showing the outcome.
